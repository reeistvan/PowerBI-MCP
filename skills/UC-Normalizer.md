# UC Normalizer

## Cél
Szabad szöveges üzleti Power BI riportigény átalakítása strukturált Markdown use case dokumentummá.

## Bemenetek
- üzleti igény szabad szöveges leírása
- docs/glossary.md
- use case sablon

## Kimenet
- use_cases/UC-XXX.md


## Kötelező fejezetek
- Business Objective
- User Role
- Dimensions
- Measures
- Visuals
- Security
- Acceptance Criteria
- Open Questions

## Hard rules

1. Ne találj ki üzleti fogalmat.
   
2. A glossary fogalmakat [[Fogalom_Neve]] formában hivatkozd.
   
3. Hiányzó információt az Open Questions részben jelezd.
   
4. Ne hozz létre DAX measure-t ebben a lépésben.

5. Minden use case kapjon egyedi UC azonosítót.

A módosítást csak jóváhagyás után alkalmazd.
